# Начало работы — сценарии видеоуроков (русский)

Bible Research — это библейское приложение, в котором можно читать Библию,
слушать Библию и записывать отдельные библейские места — чтобы позже размышлять
над ними, задавать о них вопросы, искать объяснения или просто никогда не
забыть те драгоценные, прекрасные жемчужины, которые вы находите в Библии.

Короткие встроенные видеоуроки YouTube для приложения
(`bibleresearch.vercel.app`). Каждое видео ~1–3 минуты, они упорядочены так,
чтобы новый пользователь мог смотреть сверху вниз: сначала анонимные функции,
затем создание аккаунта, затем всё, что требует входа. Каждый раздел служит
письменным руководством — **Шаги** можно выполнять без видео; **Запись** — это
список кадров.

## Производственные заметки

- **Аккаунт для записи:** общий UI-аккаунт `Tester5` / `password123`. Перед
  записью видео про заметки подготовьте: одну метку (например, «Подготовка
  проповеди»), одну публичную заметку с веткой комментариев.
- **Демо-переводы:** ESV (заголовки разделов + аудио с метками времени) и KJV
  (встроен, работает офлайн). В видео о переводах покажите «Сгенерированный
  голос» латышского GLU8. У некоторых файлов нет аудио или заголовков —
  выбирайте правильный перевод для каждого сценария, иначе демо не получится.
- **Регистрация на камеру создаёт настоящий аккаунт** — используйте одноразовое
  имя пользователя или подготовьте удаление потом.
- **Мобильный vs десктоп:** на экранах ≥768px выбор книги — постоянная боковая
  панель; на телефонах он открывается через заголовок отрывка в нижней панели.
  Записывайте в узком окне, когда показываете мобильный сценарий.
- Делайте каждое видео самодостаточным: назовите цель одной строкой, покажите
  демо, повторите итог одной строкой.

## 1. Обзор приложения (~90 с)

**Учит:** для чего нужны основные области экрана и как открыть меню.

### Шаги

1. Откройте сайт — вы попадаете на `/bible` к отрывку по умолчанию.
2. Верхняя панель содержит: лупу (поиск), кнопку воспроизведения (аудио),
   «Сменить перевод» и меню-бургер справа.
3. Нижняя панель имеет стрелки глав ‹ › вокруг центрированного заголовка
   отрывка («Иоанна 1»).
4. Прокрутите вниз — верхняя и нижняя панели уезжают для чтения без отвлечений;
   прокрутите вверх, чтобы вернуть их.
5. Нажмите бургер — выдвижное меню показывает: Аккаунт / Войти, Читать Библию,
   Начало работы (та самая страница, на которой живут эти
   уроки), Связаться с разработчиком, переключатель темы. Используйте переключатель: тёмная → светлая →
   тёмная.
6. Закройте меню через ✕ или Esc.

### Запись

- Анонимная сессия.
- Прокручивайте медленно — быстрая прокрутка делает демо автоскрытия дёрганым.
- Переключатель темы есть только в выдвижном меню — не ищите его в верхней
  панели.
- На Android в меню также виден пункт «Скачать приложение для Android» (см.
  §17).
- Указывайте на каждый элемент, называя его, чтобы зрители связали названия с
  пикселями.

## 2. Перейти к любому стиху (~2 мин)

**Учит:** переходить к любому отрывку по книге, главе и стиху.

### Шаги

1. Нажмите заголовок отрывка («Иоанна 1») в нижней панели — откроется панель с
   тремя колонками: Книги | Главы | Стихи.
2. Нажмите **Псалмы** в Книгах — список глав заполнится.
3. Нажмите **23** — вы попадаете на Псалом 23 (`/bible/PSA.23`).
4. Откройте панель снова и нажмите **1** в Стихах — стих 1 выбран, и URL
   становится `/bible/PSA.23.1`.
5. Используйте нижнюю стрелку › для перехода к следующей главе (Псалмы 24, 25).
6. На телефоне или трекпаде сделайте свайп влево для следующей главы, вправо —
   для предыдущей.
7. URL можно пересылать — вставьте `/bible/PSA.23` в новую вкладку, и откроется
   тот же отрывок.

### Запись

- Записывайте в узком окне — на десктопе панель является постоянной боковой
  панелью, поэтому сценарий с нажатием на заголовок невидим на широких экранах.
- Выбор книги может восстановить сохранённую позицию чтения вместо главы 1 —
  проговорите это («приложение помнит, где вы остановились в каждой книге»).

## 3. План книги по заголовкам разделов (~60 с)

**Учит:** переходить в любое место книги по плану заголовков разделов.

### Шаги

1. Откройте книгу с большим числом заголовков, например Псалом 18 или Иоанна 3.
2. Нажмите встроенный заголовок раздела («Никодим приходит к Иисусу») — экран
   переключится на «Иоанна — план главы».
3. План показывает заголовки соседних глав и подгружает ещё по ходу прокрутки.
4. Нажмите заголовок за несколько глав — вы сразу перейдёте к этому разделу в
   тексте.

### Запись

- Только ESV — у KJV нет данных заголовков, и ничего не произойдёт.
- План никак не подписан — скажите «нажатие на заголовок открывает план», чтобы
  зрители могли это повторить.

## 4. Выберите стихи, поделитесь ими, откройте в другом месте (~2.5 мин)

**Учит:** выбору стихов, пересылке отрывка и открытию его на внешних сайтах для
изучения.

### Шаги

1. На `/bible/JHN.3` нажмите стих 16 — он подсветится, и появится панель
   действий («Выбран 1 стих»).
2. Нажмите стихи 17–18, чтобы расширить выбор («Выбраны 3 стиха»); нажмите
   выбранный стих ещё раз, чтобы снять выбор. (Десктоп: нажмите 16, затем
   Shift+клик на 18 для диапазона.)
3. URL теперь `/bible/JHN.3.16-18` — им можно делиться.
4. Нажмите значок «Поделиться» — на телефоне откроется системное меню
   пересылки; на десктопе текст отрывка + ссылка копируются, и тост
   подтверждает.
5. Внешние значки открывают отрывок в другом месте: «Посмотреть на карте»
   открывает встроенное модальное окно «Карты Библии»; YouVersion, BibleHub,
   Blue Letter Bible и BibleMapper открывают внешние вкладки.
6. Снимите выбор через ✕.

### Запись

- Оставайтесь анонимным — значок закладки «Добавить заметку» появляется только
  при входе; пропустите его и сошлитесь на видео про заметки.
- Нажимайте достаточно медленно, чтобы каждая подсветка регистрировалась;
  сделайте паузу на тосте копирования.
- Задержите курсор на каждом внешнем значке; продемонстрируйте один (Карты
  Библии самые наглядные), не открывайте все.

## 5. Смените перевод Библии (~2 мин)

**Учит:** выбору перевода; текст и аудио выбираются независимо.

### Шаги

1. Верхняя панель → «Сменить перевод» — откроется модальное окно выбора.
2. Вкладки: Английский / Латышский / Русский / Другой.
3. На английской вкладке откройте «Версия» — значки отмечают версии «Аудио»,
   «Только текст», «Только аудио».
4. Выберите **KJV** — появится одноразовое уведомление «Загрузка Библии KJV…»
   (он встроен и дальше работает офлайн).
5. В группе «Аудио» выберите: Нет / Чтение / Драматизация / Сгенерированный
   голос — каждый с меткой охвата.
6. Переключитесь на латышскую вкладку и выберите латышскую версию — она
   предлагает аудио «Сгенерированный голос» (применяется при «Сохранить»).
7. (Необязательно) На вкладке «Другой» введите название языка и выберите его.
8. Сохраните — глава перерисуется в новом переводе.

### Запись

- Не нажимайте «Сохранить», пока идёт загрузка KJV (кнопка всё равно
  отключена).
- Некоторые версии охватывают только один завет — подсказка об охвате ожидаема,
  это не баг.

## 6. Слушайте главу (~2 мин)

**Учит:** воспроизведению аудио главы и использованию панели плеера.

### Шаги

1. На главе нажмите кнопку ▶ в верхней панели — внизу появится панель плеера.
2. Панель показывает: заголовок, ⏮/⏯/⏭, переключатель повтора, ползунок
   перемотки, время.
3. Читаемый стих получает синюю кромку и автопрокручивается по мере
   воспроизведения аудио.
4. Перемотайте вперёд на 5 с или перетащите ползунок; включите повтор для
   цикла.
5. Дайте главе закончиться — воспроизведение автоматически перейдёт к следующей
   главе.
6. На Android воспроизведение продолжается с выключенным экраном, с элементами
   управления на экране блокировки / в медиа-уведомлении.
7. Закройте плеер через ✕.

### Запись

- Нужен файл с метками времени — ESV или вариант DBT «Чтение». У аудио KJV нет
  подсветки стихов, поэтому демо с синей кромкой там не получится.
- Оранжевый значок предупреждения означает отсутствие аудио для этого
  перевода/книги — сначала переключитесь.

## 7. Аудио-плейлисты (~90 с)

**Учит:** непрерывному прослушиванию дальше одной главы — из результатов поиска
или отрывков заметок.

### Шаги

1. На `/search` найдите «вера» — у каждого стиха-результата есть маленький ▶.
2. Нажмите один — плеер запускает очередь, проходящую по результатам.
3. На `/notes/tag/<tag>` нажмите **Воспроизвести отсюда** на карточке заметки —
   воспроизводятся связанные отрывки всех заметок, начиная с этой.
4. «Перейти к отрывку» переносит вид Библии к тому, что сейчас звучит.

### Запись

- Сначала войдите — половина про заметки этого требует.
- Нужно аудио на переводе заметки; заметки без стихов воспроизвести нельзя.
- Сделайте коротко — видео формата «а вы знали».

## 8. Ищите в Библии (~90 с)

**Учит:** полнотекстовому поиску и горячей клавише `/`.

### Шаги

1. Нажмите `/` в любом месте (или лупу) — откроется `/search`.
2. Введите «light of the world» → Enter — результаты появятся в аккордеоне,
   сгруппированном по книгам («Иоанна (2)», «Матфея (1)»), с превью из 3
   стихов.
3. «Показать ещё N стихов» раскрывает результаты книги.
4. Нажмите стих — откроется `/bible/JHN.8.12` с выбранным стихом.

### Запись

- Проговорите: поиск идёт по **текущему выбранному текстовому переводу** — ESV
  и KJV дают результаты с разными формулировками.
- Если текстовый перевод не выбран, страница пишет «сначала выберите перевод
  Библии» — это не глобальный поиск.

## 9. Создайте аккаунт и войдите (~2 мин)

**Учит:** регистрации, входу, выходу — и тому, что открывает аккаунт.

### Шаги

1. Бургер → Аккаунт → Войти → `/login` → «Создайте его сейчас» → `/register`.
2. Заполните имя пользователя, электронную почту (необязательно — «используется
   для восстановления пароля»), пароль (≥8 символов), подтверждение → Создать
   аккаунт.
3. Появится тост об успехе, и вы попадёте на `/notes`.
4. Откройте меню снова — строка аккаунта показывает ваш аватар + имя
   пользователя, и появились новые пункты: Мои заметки, Новая заметка,
   Управление метками.
5. Выйдите: меню имени пользователя → Выйти → тост → `/login`. Войдите снова.

### Запись

- Настоящая регистрация создаёт настоящий аккаунт — используйте одноразовое имя
  пользователя или обрежьте до отправки.
- Правила пароля проверяются на клиенте.
- Проговорите: пользователи без входа всё ещё могут читать, слушать и искать;
  аккаунт хранит заметки, метки, комментарии и синхронизирует позиции чтения.

## 10. Сделайте заметку к стихам (~2.5 мин)

**Учит:** прикреплению заметки к выбранным стихам.

### Шаги

1. На `/bible` выберите Иоанна 3:16–17 — появится панель действий.
2. Нажмите значок закладки («Добавить заметку») — откроется модальное окно
   заметки.
3. В окне показаны тексты связанных стихов, плюс «N связанных заметок», если
   существующие заметки уже покрывают эти стихи.
4. Выберите метку из выпадающего списка.
5. Напишите предложение — или оставьте пустым, чтобы сохранить чистую закладку
   на стихи.
6. Включите **Автосохранение** — сделайте паузу, и мигнёт зелёная ✓.
7. Включите **Публичная заметка**, если любой, у кого есть ссылка, должен иметь
   возможность её просмотреть.
8. Отправьте — заметка попадёт в список заметок метки.

### Запись

- Записывайте с авторизацией — кнопка добавления заметки невидима без входа — с
  заранее подготовленной хотя бы одной меткой.
- Явно упомяните случай пустой заметки-закладки.
- Модальное окно добавления заметки на весь экран по замыслу, включая десктоп.

## 11. Редактор заметок (~2.5 мин)

**Учит:** редактору заметок с форматированным текстом — форматирование, ссылки
на Писание, изображения, автосохранение.

### Шаги

1. Примените жирный шрифт, список, цитату через панель инструментов.
2. Введите `@` плюс название книги (например, `@иоан`) — появится выбор
   отрывка; продолжайте печатать или нажмите, чтобы вставить `@JHN.3.16` как
   токен ссылки.
3. Одиночный клик по токену открывает всплывающее превью отрывка; двойной клик
   открывает выбор заново для правки.
4. Кнопка «Изображения» прикрепляет фото (миниатюры; макс. 10).
5. «Автосохранение» сохраняет каждые 5 с; переключатель «Публичная заметка»
   находится в нижней панели.
6. Отправьте.

### Запись

- `@` создаёт ссылки на *Писание*, а не упоминания пользователей — проговорите
  это.
- Ввод `@` без распознаваемой книги всё равно показывает выбор — продолжайте
  печатать название книги.

## 12. Просматривайте и упорядочивайте заметки (~2 мин)

**Учит:** странице заметок — фильтрация, сортировка, изменение порядка,
сворачивание стихов.

### Шаги

1. Меню → Мои заметки — перенаправляет к последней использованной метке
   (`/notes/tag/:tagId`).
2. Панель инструментов: **Фильтр по метке** (включая «Без меток»),
   **сортировка** (Своя / По дате / По стиху), **размер страницы**
   (5/25/50/100), **свернуть/развернуть стихи**, обновить, значок пересылки
   ссылки на метку.
3. На карточке заметки нажмите текст стиха, чтобы выбрать его — появится та же
   панель действий (включая «Открыть в Библии»). На карточке также есть значок
   перехода «Открыть в Библии», карандаш редактирования, корзина.
4. При своей сортировке перетащите карточку заметки, чтобы изменить порядок —
   значок `#k` показывает её позицию.
5. «Включить подметки» объединяет заметки поддерева с группировкой по меткам
   (только если у метки есть дочерние).

### Запись

- Подготовьте метки заранее — `/notes` без меток показывает «Создайте свою
  первую метку», и демо не получится.
- Правка/удаление показываются только на ваших собственных метках.

## 13. Метки: организуйте заметки и делитесь ими публично (~2.5 мин)

**Учит:** дереву меток — создание, смена родителя, публикация меток.

### Шаги

1. Меню → Управление метками (`/tags`) → «Новая метка» → имя + необязательная
   родительская метка.
2. Дерево показывает значки папок для родителей, значки числа заметок, значки
   поддерева `+k`; разворачивание/сворачивание; нажмите метку-лист, чтобы
   открыть её заметки.
3. Перетащите ручку метки на другую метку, чтобы сменить родителя — во время
   перетаскивания появляется закреплённая полоса «Переместить на верхний
   уровень».
4. Действия строки: **значок глобуса** → «Сделать метку публичной»
   (подтверждение объясняет, что все заметки под ней станут доступны по ссылке;
   появляется бирюзовый значок); правка для переименования/смены родителя;
   удаление (предупреждает, что заметки потеряют метку).
5. Поле поиска фильтрует дерево.

### Запись

- Скажите явно: удаление метки не удаляет заметки — они уходят в «Без меток».
- Публичность — это каскад — прочитайте предупреждение модального окна
  подтверждения вслух.

## 14. Поделитесь заметкой или меткой (~90 с)

**Учит:** модели публичного обмена — ссылки, работающие без входа.

### Шаги

1. На карточке публичной заметки нажмите значок «Поделиться» — копируется
   `/notes/<id>` (или открывается системное меню пересылки на телефоне).
2. Откройте ссылку инкогнито — заметка + комментарии видны **без входа**.
3. Публичная метка работает так же — её ссылка даёт анонимным зрителям
   публичные заметки метки.
4. Верните заметку в приватную — ссылка перестаёт работать («Заметка не найдена
   или не является публичной»).

### Запись

- Значок «Поделиться» есть только у **публичных** заметок.
- Анонимные зрители могут читать, но не комментировать («Войдите, чтобы
  комментировать») — покажите эту строку.

## 15. Комментарии к заметкам (~2 мин)

**Учит:** веткам комментариев к заметкам.

### Шаги

1. На карточке заметки нажмите кнопку счётчика 💬 — ветка раскроется встроенно.
2. Напишите комментарий — форматированный текст (жирный, списки, ссылки на
   Писание через `@`) — прикрепите изображения через **Изображения** (макс. 5)
   → Отправить.
3. Ответьте на комментарий — он вложится; свои комментарии можно редактировать.
4. Удаление своего комментария оставляет заглушку «[deleted]».
5. Ветки обновляются примерно каждые 30 с.

### Запись

- С авторизацией; заметка с заранее подготовленной веткой.
- Кнопка комментария показывается только при входе ИЛИ когда комментарии уже
  есть.
- Лимит изображений — 5 (заметки позволяют 10).

## 16. Ваша позиция чтения следует за вами (~60 с)

**Учит:** возобновлению для каждой книги; позиция синхронизируется между
устройствами при входе.

### Шаги

1. Прочитайте часть Иоанна 3; перейдите к Римлянам 5.
2. Откройте панель книг снова и нажмите **Иоанна** — вы вернётесь к Иоанна 3,
   где остановились.
3. Перезагрузите страницу — сохранённый стих восстановится.
4. При входе позиция синхронизируется с вашим аккаунтом — войдите на втором
   устройстве или в другом браузере, и та же позиция восстановится.

### Запись

- Говорите честно: серверная синхронизация — только при входе — анонимный
  пользователь получает локальное восстановление в том же браузере.

## 17. Дополнительно: тёмная тема, сообщения о проблемах, приложение для
Android (~90 с)

**Учит:** переключателю темы, сообщениям о проблемах и приложению для Android.

### Шаги

1. Переключатель темы (солнце/луна) находится в меню — тёмная тема по
   умолчанию.
2. «Связаться с разработчиком» → оставьте «Сообщение об
   ошибке» (или выберите другую категорию) → опишите проблему
   → «Отправить» → тост; текущий отрывок прикрепляется
   автоматически.
3. В браузере телефона Android меню показывает «Скачать приложение для Android»
   → APK → разрешите «установку неизвестных приложений» при запросе.
4. Внутри установленного приложения меню вместо этого показывает «Проверить
   обновления».
5. Повторите горячие клавиши: `/` открывает поиск, `Esc` закрывает модальные
   окна.

### Запись

- APK устанавливается напрямую (нет листинга в Play Store) — Play Protect может
  предупредить; скажите об этом.
- Пункт загрузки существует только на user-agent'ах Android; «Проверить
  обновления» — только внутри нативной оболочки.
